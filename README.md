9-最少取位实现异常点查找
把数据转化为双精度浮点数，共有52位有效数字，依次把最后位替换为0，则可逐渐降低精度。对于训练集而言，初始降低精度时训练出的模型性能不会突然下降，呈缓慢下降趋势，当替换精度到某一位（设为n）时，模型性能会出现突然下降，目的是找到这个突变点n
约束如下：
a.总数量为52（即n∈[0,52])，每次降低精度后计算模型性能p(n)代价很高（即尽量少的计算p）
b.P(k) 非单调，存在轻微随机波动；
c.存在一个唯一的剧烈下降点 n，使得 D(n)=P(n−1)−P(n)≫ 所有其他 D(k)；
d.必须输出确切的整数 n（不能是区间或近似）；
e.每次调用 P(k) 返回一个实数值，可任意精度比较；
f.允许自适应查询（后一次查询可依赖前几次结果）；
g.突变量未知
方法：
1.首先计算p(0),p(17),p(34),p(52),找到max(D(i)-D(j)),i,j∈{0，17，34，52}，且i，j在{0，17，34，52}中相邻（计算p四次）
2.把[i,j]三等分，不失一般性，设i=34,j=52，此时取p(40),p(46),找到max(D(i)-D(j)),i,j∈{34，40，46，52}，且i，j在{34，40，46，52}中相邻（计算p两次）
3.再次执行上步，不失一般性，设i=46,j=52，此时取p(48),p(50),找到max(D(i)-D(j)),i,j∈{46，48，50，52}，且i，j在{46，48，50，52}中相邻（计算p两次）
4.再次执行上步，不失一般性，设i=50,j=52，此时取p(51),找到max(D(i)-D(j)),i,j∈{50，51，52}，且i，j在{50，51，52}中相邻（计算p一次）
5.此时即可得出p(n)变化最大时的n，共需计算9次，即训练模型9次。
